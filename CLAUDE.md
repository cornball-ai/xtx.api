## Project Overview

xtxapi is an R package providing a unified interface for cross-modal generative models, enabling transformations between text, image, audio, and video modalities. It integrates with the sttapi (speech→text) and ttsapi (text→speech) packages.

Supported modalities: text→image, text→video, image→video, audio→video

Backends: Diffusion models, talking-head systems (SadTalker, DiD), hosted APIs (OpenAI, Replicate)

## Common Commands

```bash
# Build and check package
R CMD build .
R CMD check xtxapi_*.tar.gz

# Install package locally
R CMD INSTALL .

# Generate documentation (requires roxygen2)
Rscript -e "devtools::document()"

# Run tests (when added)
Rscript -e "devtools::test()"

# Run a single test file
Rscript -e "testthat::test_file('tests/testthat/test-example.R')"
```

## R Package Structure

- `R/` - R source files with exported functions
- `man/` - Documentation (auto-generated by roxygen2 from R comments)
- `tests/testthat/` - Unit tests using testthat
- `DESCRIPTION` - Package metadata and dependencies
- `NAMESPACE` - Exports (auto-generated by roxygen2)
